`npm i` to install all required dependencies<br>
`npm run start:studio` to run the `/build` Cornelia Studio at `localhost:32302`<br>
`npm run dev:studio` to develop the `/src` Cornelia Studio live at `localhost:32312`<br>
`npm run dev:cornelia` to develop Cornelia<br>
`npm run build` to compile and copy files to `/build`<br>
`npm run clean` to delete `/build`, `/dist`, and other temp files<br>
`npm run package:studio:windows` to package Cornelia Studio `/build` for Windows<br>
`npm run package:cornelia:windows` to package Cornelia `/src` for Windows<br>
`npm run package:windows` to package both Cornelia Studio and Cornelia for Windows<br>
Run `inno.iss` via Inno to combine the packaged .EXEs as an installer to `/dist`

To open `/templates/*.free`, [Lunacy](https://lunacyapp.com) is required<br>
